# FC Barcelona Fan Web App

## Project Description
This is a responsive frontend ReactJS web application for FC Barcelona fans. It combines the old HTML/CSS football club website into a modern React project with multiple pages, images, match schedule, squad cards, gallery, and contact form.

## Pages
- Home
- About
- Team
- Matches
- Gallery
- Contact

## Technologies Used
- ReactJS
- Vite
- CSS3
- Responsive design
- Git / GitHub-ready structure

## Setup Instructions
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run:
```bash
npm install
npm run dev
```
4. Open the local URL shown in the terminal.

## Build for Hosting
```bash
npm run build
```
Upload the project to GitHub and deploy using Vercel, Netlify, or GitHub Pages.
